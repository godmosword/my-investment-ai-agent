# 日報 V2（版面與敘事規格）

本文件對齊 `crew.py` 內 **【日報 V2】** 與 **【AI 段風險預算銜接】**，目標是：**30 秒讀懂 regime 與主線、可執行交易不超量、全文只有一套總風險敘事**。

## 1. 區塊順序（加密上半部）

1. 標題（含日期）
2. 【上期建議追蹤】（BQ 權威；LLM 勿改寫）
3. 【今日市場模式】+ 評分卡明細
4. **· 今日主敘事：** 單句（≤45 字），與主 regime 一致
5. 🏛️ 宏觀框架
6. 📊 加密市場：區塊①～④
7. （系統注入）【SourceHealth】等三行 — **勿寫在儀表板內**
8. `[QSREC_START]` …（與 AI 段 QSREC 合併為同一陣列時由 pipeline 拼接）

## 2. 區塊順序（AI 下半部）

1. 🏛️ 承上宏觀（不重複貼利率整段）
2. 🤖 AI 市場：儀表板 + **〔新聞 4〕～〔新聞 6〕**（格式同幣圈，禁止 `1.2.3.` 當新聞編號）
3. 呢喃
4. 精準操作：**訊號衝突摘要** → **美股部位框**（不要第二份「今日風險預算：總風險預算 XX%」）
5. QSREC（若與加密分開輸出則由 `main.py` 合併）

## 3. 語氣（neutral / 缺資料）

- 禁止：歷史底部明確、必漲必跌、絕佳進場點等**過度確定**用語。
- 允許：若…則…、證據不足、機率偏…、條件式風控。

## 4. 儀表板可讀性

- 每行一個指標；`<code>N/A</code>` 後若需說明，**換行**再寫，避免 `N/ACoinGlass…`。
- Pipeline 會執行 `_fix_glued_na_suffix` 作為保險。

## 5. Gate / 驗證（`main.py`）

- **多組總風險預算百分比衝突**：`validate_report` 會提示整併。
- **QSREC 同 category + 同 asset 不得 LONG+SHORT 並存**：否則驗證失敗並觸發重試。

## 6. 相關程式

- 提示詞：`crew.py` → `_BRIEF_V2_RULE`、`_AI_RISK_BRIDGE_RULE`
- 後處理：`main.py` → `_fix_glued_na_suffix`、`_postprocess_report_for_resilience`
